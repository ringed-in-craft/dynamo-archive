# Quarterly Revenue Report — Authoritative Specification

This document is the complete and authoritative specification for the quarterly
revenue report generated by this pipeline. Every requirement listed here must be
implemented exactly.

## Output Format

File: /app/output/report.csv

Columns in order: year, quarter, total_orders, total_revenue, total_discount, total_shipping

- year: integer (e.g., 2023)
- quarter: integer 1-4 (1=Jan-Mar, 2=Apr-Jun, 3=Jul-Sep, 4=Oct-Dec)
- total_orders: count of distinct orders included in the quarter
- total_revenue: sum of all line-item revenue (quantity * unit_price), rounded to 2 decimal places
- total_discount: sum of order-level discounts, rounded to 2 decimal places
- total_shipping: sum of shipping costs, rounded to 2 decimal places

## Included Orders

Only orders with status 'completed' or 'pending' are included.
Orders with status 'cancelled', 'refunded', or NULL status are excluded.

## Revenue Calculation

Revenue is the sum of (quantity * unit_price) across all line items in included orders.
Orders with zero line items contribute 0 revenue.

## Discount Calculation

Discount is applied at the order level.
For each included order with at least one line item:
  discount = MIN(discount_pct, 0.20) * subtotal

The discount percentage is capped at 20%. Any discount_pct value above 0.20
is treated as 0.20. For example, an order with discount_pct = 0.25 and
subtotal = $100.00 contributes $20.00 (not $25.00) to the discount total.

Orders with zero line items contribute 0 discount.

## Shipping Calculation

Shipping is per-order. Use a LEFT JOIN to include all orders, even those
without a shipping record. Orders with no shipping record contribute 0 to
the shipping total. Orders with zero line items contribute 0 shipping.

## Rounding

All monetary values in the output must be formatted with exactly 2 decimal
places (e.g., "25694.00", not "25694.0").
